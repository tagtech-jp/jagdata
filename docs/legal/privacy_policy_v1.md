# プライバシーポリシー

最終更新: 2026年5月27日 (v1.0)

## 個人情報保護方針

TagTech (以下「当方」)は、本サービス「jagdata」(マイジャグラーV 設定判別ツール、以下「本サービス」)のご利用にあたりお預かりするお客様の個人情報を、個人情報の保護に関する法律(以下「個人情報保護法」)その他関係法令を遵守して適切に取り扱います。

## 取得する個人情報

本サービスのご利用にあたり、以下の情報を取得します。

- **LINEユーザーID**: LINE Messaging API を通じて自動的に取得します。お客様のLINE上での個人名・プロフィール画像等は取得しません。
- **送信された画像**: 設定判別を行うためにお客様が送信した遊技台画面の画像。
- **判定リクエスト履歴**: 利用日時、判定結果の概要。

## 利用目的

取得した個人情報は、以下の目的に限定して利用します。

- 本サービスの提供(画像解析と設定判別の実施)
- 本サービスの品質向上、不具合の調査・対応
- 不正利用の検知・防止
- 当方からの重要なお知らせの送信

## 個人情報の取扱いの委託

本サービスの提供にあたり、以下の事業者へお客様の個人情報の取扱いを委託しています。委託先における個人情報の取扱いについては、当方が適切な監督を行います。

| 委託先 | 委託の目的 | 所在地 |
|---|---|---|
| Google LLC(Gemini API) | 画像からの数値抽出のための画像解析 | 米国 |
| Cloudflare, Inc.(Cloudflare Workers) | サービス基盤のホスティング | 米国 |
| LINE株式会社 | LINE Messaging API による通信 | 日本 |

これらの委託先における個人情報の取扱いは、各社のプライバシーポリシーに従います。

## 外国にある第三者への提供について

本サービスでは、上記のとおり米国に所在する事業者(Google LLC、Cloudflare, Inc.)に個人情報の取扱いを委託しています。米国における個人情報の保護に関する制度の詳細は、個人情報保護委員会のウェブサイト等をご参照ください。

## 個人情報の保管期間

- **送信された画像**: 判定処理の完了後、速やかに削除します。
- **判定リクエスト履歴**: 本サービスの運営に必要な期間、適切に保管します。
- **LINEユーザーID**: お客様が本サービスのご利用を停止されるまで保管します。

## お客様の権利

お客様は、当方が保有するお客様の個人情報について、個人情報保護法に基づき以下の請求を行うことができます。

- 利用目的の通知
- 個人情報の開示
- 個人情報の訂正、追加または削除
- 個人情報の利用停止
- 個人情報の第三者提供の停止

請求方法等につきましては、下記「お問い合わせ窓口」までご連絡ください。本人確認のうえ、合理的な期間内に対応いたします。

## 安全管理措置

当方は、お客様の個人情報の漏えい、滅失、毀損の防止その他の安全管理のため、以下の措置を講じます。

- 個人情報を取り扱う端末・通信経路の適切な管理
- アクセス制限・認証管理の実施
- 不正アクセス対策の実施

## Cookie・類似技術について

本サービスは LINE Messaging API 経由のメッセージ送受信のみを行い、お客様のブラウザに Cookie 等を設定することはありません。

## 本サービスの利用停止

お客様が本サービスのご利用を停止される場合は、LINE 上で当方のアカウントをブロックすることでご利用を停止いただけます。ご利用停止後、当方が保有するお客様の判定リクエスト履歴等の個人情報は、合理的な期間内に削除いたします。

## 本ポリシーの変更

本ポリシーは、法令の改正その他の事情により変更する場合があります。重要な変更がある場合は、本サービス内またはウェブサイト上にて公表します。
